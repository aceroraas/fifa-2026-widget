🏆 Copa Mundial FIFA 2026

Mirá abajo a la derecha — ahí está el widget flotante como Web Component.

Cómo usarlo en tu HTML

<!-- 1. Cargá el script -->
<script src="fifa-world-cup.js"></script>

<!-- 2. Usalo como tag -->
<fifa-world-cup></fifa-world-cup>

<!-- Opciones -->
<fifa-world-cup position="top-left"></fifa-world-cup>
<fifa-world-cup position="top-right"></fifa-world-cup>
<fifa-world-cup position="bottom-left"></fifa-world-cup>
<fifa-world-cup position="bottom-right"></fifa-world-cup>
<fifa-world-cup theme="light"></fifa-world-cup>

Actualizar datos desde JavaScript

const widget = document.querySelector('fifa-world-cup');

// Actualizar un partido (índice 0 = México vs Alemania)
widget.actualizarPartido(0, {
  golLocal: 2,
  golVisitante: 1,
  estado: 'finalizado'
});

// Ver todos los datos
console.log(widget.obtenerDatos());

// Forzar actualización desde API
widget.forzarActualizacion();

El widget tiene Shadow DOM encapsulado — no interfiere con los estilos de tu página.
